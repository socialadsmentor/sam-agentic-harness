# Changelog

## v0.1.0 - first public edition

Initial public release: a scrubbed copy of the rules, on-demand skill library, hook scripts,
self-harness loop tooling (with 3 starter eval cases and their fixtures), and the guided
installer (`/harness-install`), adapted from a production Claude Code configuration. Some
skills are redistributed unmodified; others were adapted (voice, formatting, worked examples
removed where present); a small number of skills with unverifiable licensing were left out
entirely (see `NOTICE.md`).
